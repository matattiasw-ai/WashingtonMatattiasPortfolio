About the Project

About SiteSpy

SiteSpy is a mobile-first construction project records and cost estimation app built with Expo React Native, Firebase, and Firestore. It helps construction teams capture measurements, estimate material costs, organise site records, and review project history on any device — even in low-connectivity field conditions.

My Reflection

Coordinating 18 contributors is a different kind of technical challenge. I learned that the integration phase is where small oversights become big blockers — mismatched dependencies, undocumented config values, or conflicting Firestore rule changes. Clear documentation and a tracked work division plan kept the team aligned and the final submission clean.
